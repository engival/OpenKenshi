# Contributing

Contributions are welcome and are accepted under this project's license, [MIT](LICENSE). By contributing you agree
that your work is licensed under it.

There is no contributor license agreement. Instead, sign off each commit with the
[Developer Certificate of Origin](https://developercertificate.org/): add a `Signed-off-by:` line with your name and
email (`git commit -s` does it), certifying that you wrote the change or otherwise have the right to submit it.

Ground rules:

- Never commit game files: no data, meshes, textures, sounds, screenshots or other material taken from Kenshi.
- Never copy code from the game or from decompiled output. Reverse-engineering references may be read as
  documentation; write your own code, and credit them in [CREDITS.md](CREDITS.md).
- Bundled libraries must use a permissive license (MIT, BSD, zlib, Apache-2.0, public domain); no GPL-family code.
