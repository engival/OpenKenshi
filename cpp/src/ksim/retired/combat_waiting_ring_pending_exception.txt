Retired 2026-11-01 (cadence follow-up 13, kinspect 48 (c)) from src/ksim/combat.cpp (Ctx::waitingRing, follow-up 12). The hold's steer was
off only while `pending == Defend` and the target was in the swing state. `pending` (our hub-pick field) is stale in the hold, so the servant
after a blocked BB read as "standing" and never pushed. Replaced by Member::hold (trackPending: the exe's +0x1f4 set on the opponent's swing
start, cleared by the holder's own swing start or the opponent's swing end; entry rule from own swing vs from a block) and holdPush (the
per-frame lag toward 16 u/s).

	Steer waitingRing(Fighter& f)
	{
		double n = 0.0;
		for (const state::FighterSlot& slot : f.slots)
			n += slot.holder != 0 ? 1.0 : 0.0;
		const Member* t = f.target != 0 ? member(f.target) : nullptr;
		const bool standing = f.pending == CombatState::Defend && t != nullptr && t->fighter.state == CombatState::Attack;
		return {true, n * 0.25 + 15.0 + kFollowOffset, n * 3.0 + 25.0 + kFollowOffset, kTuneWalkCap, false, !standing};
	}
